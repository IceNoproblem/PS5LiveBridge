第 1 步 · 把推流地址指到这台电脑

未配置

PS5 开播时会把画面推给 Twitch。只要让这段推流先到这台电脑 （—），就能转去 B 站。

这一版跑在容器里，动不了宿主机的网络，所以只能从路由器入手。 加速器必须开在路由器上；如果加速器是开在电脑上的，请改用 Windows 桌面版。

方案一 · 改路由器的 hosts

把下面这几个推流域名指到这台电脑（—）， PS5 保持自动获取就行。
只动推流域名，PS5 上网、PSN、联机对战都不受影响。 这条路配一次就长期有效，PS5 重启也不丢。

或者：自动写进路由器（OpenWrt） 未探测

路由器是 OpenWrt 的话，填账号密码就能一键写进去，不用手动改。

方案二 · 开内置 DNS

路由器改不了 hosts，那就让这台电脑临时当 DNS： 把推流和 Twitch 的域名答成本机地址，PS5 的网络设置里只改 DNS 一栏。
好处是不碰路由器；代价是 PS5 每次重启都可能要重设一次 DNS， 而且这台电脑必须一直开着。

为什么必须填代理： 这条路会把 Twitch 的网页/API（443）也引到这台电脑。国内直连 Twitch 不通， 这台电脑必须有一个能上外网的通道把它转发出去， 否则 Twitch 应用打不开，你也点不到「开始直播」。

加速器是装在路由器上的，它只加速 PS5 的流量，帮不到这台电脑，所以这里要单独填一个。 写法：http://主机:端口（例 http://192.168.1.100:7890）。留空表示不使用代理。 （局域网里另一台跑 Clash/mihomo 的机器也可以）。
内置 DNS 已开启。现在去 PS5 上把 DNS 那一栏改成这台电脑的 IP（—）， 其余三栏照原来的值填（PS5 不允许 IP 自动、DNS 手动混着来）。

方案三 · 开流量接管

在本机网卡层直接拦下 PS5 的推流，不碰路由器、也不改 DNS。 需要以管理员身份运行，否则驱动加载不起来。
前提是加速器装在这台电脑上，PS5 的流量真的经过本机 —— 如果是路由器版加速器，选方案一或方案二。

第 3 步 · 把加速器的四个数填进 PS5

—

PS5 开 Twitch 直播要走加速器。加速器给四个数，四个都照抄进 PS5。

正在检测你的方案…
这台电脑的 IP（—）不要填进 PS5，哪一栏都不填。
PS5 上的项 填什么 加速器给的值
IP 地址 加速器的「IP 地址」
子网掩码 加速器的「子网掩码」
默认网关 加速器的「网关」
DNS 加速器的「DNS」

「检测加速器」只填网关和 DNS，IP 和掩码要自己抄。这四个数只是备查，可以不动，填错不影响软件。

PS5 上怎么点

  1. 设定 → 网络 → 设定互联网连接，选正在用的网络。
  2. 手柄按 Options → 高级设定。
  3. IP 地址设置改为「手动」。DNS 会一起变成手动，PS5 不让一个自动一个手动。
  4. 四个数填进去，保存。
  5. 加速器一旦关掉，PS5 会立刻断网。所以别关，让它一直开着。

第 3 步 · PS5 不用改设置

保持自动

加速器开在路由器上，路由器已经把推流地址指到这台机器 （—）。PS5 照平时上网的样子就行。

PS5 网络设置 ✓ 保持「自动获取」，别手动填 IP 和 DNS
加速器 ✓ 照常给 PS5 加速，不用关
同一局域网 ✓ PS5 和这台机器连的是同一个路由器
如果你之前按别处的教程把 PS5 改成过「手动 IP + 手动 DNS」，现在要改回自动， 否则会连到旧地址上。

未登录

点右边按钮生成二维码

还没开始。

标题留空时，开播后会自动去 Twitch 抓 PS5 上填的标题再写进直播间。 这一步要用到上面的代理（国内直连不上 Twitch）。填了标题就按你填的来，不抓。

开播前必须按这个顺序操作（点开看步骤）
  1. 关掉路由器上的加速器——它接管 DNS，会把推流地址解析成公网 IP， 这个软件就收不到 PS5 的画面了
  2. 在 PS5 → 设置 → 网络 里断开网络连接
  3. 确认 PS5 的网络设置符合第 3 步的要求 （IP / 子网掩码 / 网关 / DNS 四个数）
  4. 改完设置之后重新连接一次网络——PS5 不会自动重连， 不重连的话新 DNS 不生效
  5. 打开游戏，开始直播
  6. 确认这边画面通了之后，再把路由器的加速器打开
加速器最后再开——它只负责游戏联机的加速，不影响已经建好的推流。

常见问题排查

遇到问题先看这里

下面按「你会看到什么 → 为什么 → 怎么办」写的，不用懂技术也能照着做。 如果这里没有你的问题，去诊断页把结论发出来。

① 提示「内置 DNS 应开未开」

你会看到：诊断页写着「内置 DNS 应开未开」，PS5 也连不上。

为什么：53 端口被别的软件占了。最常见的是 UU 远程 / 网易 UU， 它有个网络优化功能会抢这个端口。

怎么办：

  1. 打开诊断页，看「端口与防火墙」里 53 那一行后面写的是谁
  2. 如果是 GameViewerService（UU 远程），去 UU 设置里关掉 「智能 DNS / 网络优化 / DNS 加速」这类选项
  3. 或者直接退出 UU，再回本程序点「启动内置 DNS」
② 开播失败，提示「检测到有异常的客户端行为」（60031）

你会看到：点开播后立刻失败，提示要等几分钟。

为什么：B 站的风控。短时间内反复开播/停播，它会以为在刷。

怎么办：

  1. 停手等 5 分钟，期间别点开播
  2. 注意：每点一次失败，等待时间会重新计时
  3. 以后一次开成，别反复试
③ 直播间画面断了 / 忽有忽无

你会看到：画面卡住、黑屏，或者中间转圈，过一会儿又好了。

为什么：两个可能：电脑忙不过来（CPU 吃满），或者网络抖动。

怎么办：

  1. 关掉浏览器里其他标签页，尤其是别的视频页面
  2. 本程序的界面别一直开着大窗口，缩到一边就行
  3. 叠加（文字/弹幕）会额外吃资源，卡的时候先关掉试试
  4. 看诊断页的 CPU 数字，长期超过 90% 就是太满了
④ 弹幕不显示在画面上

你会看到：B 站直播间有人发弹幕，但画面里看不到。

为什么：弹幕叠加没打开，或者弹幕太少还没轮到显示。

怎么办：

  1. 第 5 步「画面叠加」里确认 开弹幕 打了勾
  2. 点「保存叠加设置」，如果正在直播，画面会闪一下（正常）
  3. 自己发一条弹幕测试，大约 1 秒内出现
  4. 如果还不显示，去诊断页看「叠加」相关的报错
⑤ 本地画面预览一直是黑的

你会看到：左边预览框纯黑，没有画面。

为什么：PS5 还没开始推流。预览看的是 PS5 推过来的画面。

怎么办：

  1. 在 PS5 上打开游戏，点「开始直播」
  2. 等 5~10 秒，预览会自动出现画面
  3. 注意：预览里的文字和弹幕是模拟效果，卡顿发糊都正常，不影响推给 B 站的画面
⑥ PS5 连不上 / 开不了播

你会看到：PS5 点开始直播失败，或者一直转圈。

为什么：PS5 的 DNS 没指向这台电脑，或者加速器把 DNS 抢走了。

怎么办：

  1. 按第 3 步的要求检查 PS5 的网络设置（IP / 子网掩码 / 网关 / DNS 四个数）
  2. 改完设置后 重新连接一次网络（PS5 不会自动重连）
  3. 开播前先关掉路由器上的加速器，画面通了之后再开
⑦ 开了加速器之后画面没了

你会看到：本来好好的，一开游戏加速器直播就断了。

为什么：加速器会改 DNS，把推流地址指向公网，这台电脑就收不到 PS5 的画面了。

怎么办：

  1. 顺序很重要：先关加速器 → PS5 断网重连 → 开播 → 画面通了 → 再开加速器
  2. 加速器只负责游戏联机加速，最后开不影响已经建好的推流
⑧ 画质模糊 / 马赛克

你会看到：B 站直播间画面比 PS5 上糊。

为什么：PS5 推流的码率不够，或者网络不好自动降了码率。

怎么办：

  1. PS5 设置 → 直播 → 把画质调到最高（码率调大）
  2. 看第 5 步「画质 / 码率」，正常应该是 1080p60 + 6000kbps 以上
  3. 低于这个数说明上行带宽不够，或者网络在丢包
⑨ PS5 连不上，但电脑上网正常

你会看到：电脑能上网，PS5 却连不上本程序。

为什么：Windows 防火墙拦住了。第一次运行时会弹提示，如果点了「取消」就会被挡。

怎么办：

  1. 打开诊断页，看「防火墙」那一行是不是 5/5 已放行
  2. 不是的话，重新运行一次程序，这次一定要点「允许访问」
  3. 或者手动在 Windows 防火墙里给本程序放行
⑩ 文字位置不对 / 拖了没反应

你会看到：在预览里把文字拖到某处，B 站画面上位置不一样。

为什么：位置是实时生效的，但需要 1~2 秒。如果正在直播，改完会短暂闪一下。

怎么办：

  1. 拖完松手，等 2 秒再看 B 站画面
  2. 拖的时候如果 B 站画面闪了一下，说明在按新位置重新渲染，正常
  3. 预览框里的位置是等比例模拟的，和实际画面对应
⑪ 程序启动后没反应 / 界面打不开

你会看到：双击程序后没窗口，浏览器也打不开。

为什么：端口被占用，或者杀毒软件拦了。

怎么办：

  1. 看任务管理器里有没有 PS5LiveBridge.exe 在跑，有就先结束
  2. 重新双击程序，第一次会弹 UAC（管理员权限），必须点「是」
  3. 还是不行就重启电脑再试
⑫ PS5 显示直播成功了，但软件没反应，B 站也没开播

你会看到：PS5 上提示「开始直播」成功，但这台电脑的界面一点变化都没有， B 站也没开播。

为什么：画面播到 Twitch 去了，没到这台电脑。 PS5 开播时会把画面推给 Twitch，正常情况这个推流应该先到本机。 如果 PS5 的 DNS 没指到本机，或者加速器临时改了 DNS， 推流就会直接走上公网，本机什么都收不到。

怎么办：

  1. 看左侧「PS5 查询」这一行，如果是「未接入」，说明 PS5 的 DNS 根本没指过来
  2. 确认本机的「内置 DNS」是运行中（不是应开未开）
  3. 去 PS5 上检查网络设置里的 DNS，必须是本案电脑的 IP（第 3 步会让你抄的那四个数）
  4. 改完 在 PS5 上重新连接一次网络，再点开始直播
  5. 如果开了游戏加速器，先关掉它再试
  6. 还不行就重启 PS5 的网络，让它重新走一次 DNS 解析
⑬ 改了设置但画面上没变化

你会看到：改了字号、颜色或者拖动位置，B 站画面还是老样子。

为什么：改文字内容会立刻变；但改字号/颜色/位置这类， 程序需要重启转码才能生效，中间会断 1~2 秒。

怎么办：

  1. 点「保存叠加设置」后等 2~3 秒，画面会闪一下，那就是在生效
  2. 如果没闪，看诊断页「转码与推流」里的转码进程是不是还在运行
  3. 没开播的时候改，要等下次开播才生效
⑭ 弹幕字太大 / 太小 / 挡住画面

你会看到：弹幕把游戏画面挡住了，或者小到看不清。

为什么：弹幕字号是按 1080p 画面算的，预览框是缩小的， 所以预览里看着小是正常的。

怎么办：

  1. 在第 5 步「画面叠加」里调「字号」，一般 32~40 比较合适
  2. 嫌挡画面就把「背景不透明度」调低，或者把弹幕拖到画面边缘
  3. 还可以减少「最多几条」，避免一次堆太多行
⑮ 直播一会儿就自动停了

你会看到：播了几分钟突然停，界面显示已停止。

为什么：PS5 那边断了（掉游戏、休眠、切后台）， 或者电脑这边的转码进程崩了。

怎么办：

  1. 看诊断页「转码与推流」的「重启次数」，次数多说明一直在崩
  2. PS5 设置里关掉「待机时暂停直播」这类省电选项
  3. 如果是转码崩，多半是叠加太复杂，先关掉弹幕叠加试试
  4. 重新开播就行，B 站那边会重新开一场
⑯ 提示「有另一台设备正在向这个频道播放」

你会看到：开播时 B 站报错，说这个直播间已经有别的设备在推流。

先说最重要的一点：这句提示不能按字面理解。 PS5 那边只要推流建立不起来，多数情况都会回这一句， 不代表真的有一台别的设备在推。所以不要一上来就去翻别处的设备。

可能的原因（从最常见的往下排）：

  • 上一场直播没断干净——最常见。上次异常退出、断网、直接关机， B 站那边还以为你在播
  • PS5 自己重连了一次——网络抖动导致它建立了第二路推流， 两路打架，B 站就回这句
  • 加速器或代理插了一脚——把推流地址解析到别处，看着像另一个来源
  • 本程序上次异常退出，推流进程还挂在后台没退
  • 真的另一台设备在用同一个账号推流（OBS、手机、另一台电脑）
  • 账号在别处登录着，那边正在直播

怎么办（按顺序试，前面几步能解决大部分）：

  1. 在本程序里点一次「停止直播」，等 10 秒，再点「手动开播」
  2. 如果还报，等 3~5 分钟，让 B 站自然释放上一路推流，再开
  3. 去 B 站网页版「直播中心」看一眼，如果显示「直播中」但你没在播， 手动点「结束直播」
  4. 在 PS5 上退出直播，重新连接一次网络，再重新开播
  5. 关掉路由器上的游戏加速器再试（它会改 DNS 和推流路径）
  6. 任务管理器里看有没有残留的 ffmpeg.exe，有就结束掉
  7. 以上都不行，才去排查别的设备：检查 OBS、手机、其他电脑是否在推这个直播间
  8. 最后手段：把 B 站账号在其他设备上退出登录

遇到这条提示，优先怀疑「上一场没断干净」和「PS5 重连」， 而不是急着去找第二台设备。

⑰ 开播正常，但 PS5 画面里看不到弹幕

你会看到：B 站直播间有人发弹幕，但游戏画面上没有。

弹幕要走两段路才到 PS5，断在哪一段，处理方法不一样。 先看网页界面能不能看到弹幕，这一步就能定位：

情况 A：网页界面上也看不到弹幕

说明本程序和 B 站服务器之间没通，弹幕压根没收到，跟 PS5 无关。

  1. 看左侧「本机 → 弹幕服务器」这一行是不是「已连」
  2. 不是的话，先确认第 4 步扫码登录 B 站成功了
  3. B 站登录过期很常见，重新扫一次码再试
  4. 登录好了之后，自己在 B 站发一条弹幕，网页界面的「最近弹幕」里应该能看到

情况 B：网页上能看到弹幕，但 PS5 上没有

说明弹幕收到了，但本程序和 PS5 之间没通——弹幕没送到 PS5 那边。

  1. 看左侧「本机 → PS5 弹幕」这一行。显示「等待」说明 PS5 还没连上来
  2. 去诊断页看「弹幕 6667」是不是「监听中」。这一条断了就直接重开本程序
  3. 确认 PS5 和这台电脑在同一个局域网里，中间没被防火墙挡
  4. 在 PS5 上把直播停掉，重新开一次——弹幕通道是在开播时建立的
  5. 如果一直连不上，重启一次 PS5 的网络连接

判断口诀：网页也没有 → 和 B 站没通； 网页有、PS5 没有 → 和 PS5 没通。
